# Assets and copyright policy

This is a public repository.

## Do not commit extracted Microsoft assets

Do not add original Windows 95 resources extracted from Microsoft binaries, including:

- icons;
- WAV files;
- bitmaps;
- cursors;
- logos;
- DLL/EXE resources;
- proprietary fonts.

## Allowed project approaches

Use one of the following:

1. Clean-room recreation assets.
2. Original project artwork inspired by the era.
3. User-side import tools that process files the user already owns.
4. Links/instructions pointing users to official third-party projects.

## Third-party tools

The repository should not silently repackage third-party binaries unless their licenses explicitly allow redistribution and the license obligations are satisfied.

Prefer official release pages for RetroBar, Open-Shell and optional third-party tools.
